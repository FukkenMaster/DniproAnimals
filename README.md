# Притулок «Дім для хвостиків» — статичний сайт

Статичний сайт притулку для котів: головна, каталог котів із фільтрами, профілі,
сторінка адопції, контакти з формою та сторінка «Про притулок».

Технології: [Astro](https://astro.build) + Markdown-контент, збірка у звичайні
HTML/CSS/JS. Хостинг — Netlify (безкоштовний тариф).

> **Усе на сайті — тимчасові дані.** 130 котів, тексти, контакти й логотип
> згенеровані як заглушки. Замініть їх реальними даними перед публікацією.

---

## Швидкий старт

```bash
npm install
npm run dev        # локальний сервер: http://localhost:4321
npm run build      # збірка сайту в папку dist/
npm run preview    # перегляд зібраного сайту
```

Потрібен Node.js 22 або новіший.

## 1. Редагування текстів і контактів

**Уся інформація, яку потрібно змінювати, зібрана в одному файлі:**
[`src/config.ts`](src/config.ts).

| Що змінити | Розділ у конфігу |
| --- | --- |
| Назва, опис, адреса сайту, логотип | `siteConfig` |
| Телефон, email, адреса, години, соцмережі | `contacts` |
| Пункти меню | `navigation` |
| Тексти головної | `home` |
| Тексти сторінки адопції, вимоги, ціни, FAQ | `adoption` |
| Сторінка «Про притулок» | `about` |
| Контактна сторінка та підписи форми | `contactPage` |
| Підписи профілю кота | `animalPage` |
| Підписи каталогу й фільтрів | `listingPage` |
| Статуси, стать, вікові групи | `labels` |
| Підвал сайту | `footer` |
| Сторінки 404 і «Дякуємо» | `notFoundPage`, `thankYouPage` |
| Кольори бренду | `theme` |

Кольори бренду задаються в `theme` і автоматично підставляються на всі
сторінки. У [`src/styles/global.css`](src/styles/global.css) є лише резервні
значення — змінювати їх не обов'язково.

### Після публікації

Обов'язково змініть `siteConfig.url` на реальну адресу сайту. Від неї залежать
канонічні посилання, sitemap і `robots.txt`.

## 2. Додавання кота

Кожен кіт — це один Markdown-файл у [`src/content/animals/`](src/content/animals).
Щоб додати нового кота, створіть файл, наприклад `src/content/animals/murka.md`:

```markdown
---
name: "Мурка"
sex: female            # male або female
ageMonths: 26          # вік у місяцях (26 = 2 роки)
breed: "Метис"
status: available      # available | reserved | adopted
photos:
  - "/images/animals/murka-1.jpg"
  - "/images/animals/murka-2.jpg"
traits:
  - "щеплена"
  - "стерилізована"
  - "добра з дітьми"
summary: "Мурка — ласкава кішка, яка шукає затишний дім."
intakeDate: 2026-09-12
featured: false        # true — показати на головній
---

Тут довільний текст про кота. Можна писати кілька абзаців.
```

Правила:

- **Ім'я файлу** стає адресою сторінки: `murka.md` → `/tvaryny/murka/`.
  Використовуйте латиницю, цифри та дефіси.
- **Фото** кладіть у `public/images/animals/`. У `photos` вказуйте шлях від
  кореня сайту, починаючи з `/images/...`.
- **Статуси:** `available` — шукає дім, `reserved` — зарезервовано,
  `adopted` — знайшов дім (картка стає сірою, на сторінці з'являється
  відповідне повідомлення).
- **Вік** вказується лише в місяцях — сайт сам показує «4 місяці», «2 роки» тощо.
- Якщо поле заповнене з помилкою, збірка зупиниться й підкаже, що виправити.

Щоб прибрати кота з сайту — видаліть його файл.

### Заміна тимчасових даних

Усі 130 котів згенеровані скриптом. Щоб почати з чистого аркуша, видаліть
файли з `src/content/animals/` і додавайте свої. Якщо потрібно знову
згенерувати заглушки:

```bash
npm run generate:placeholders
```

⚠️ Скрипт **перезаписує** всі `.md`-файли в `src/content/animals/`, тому не
запускайте його після додавання реальних котів.

## 3. Логотип і зображення

- Логотип: `public/logo.svg`. Замініть файл на свій (можна `.png`, тоді
  оновіть `siteConfig.logo` і `favicon` у `src/layouts/Base.astro`).
- Фото котів: `public/images/animals/`. Рекомендований розмір — 1200×900 px,
  формат JPG/WebP. Стискайте фото перед завантаженням (наприклад, Squoosh).
- Вісім SVG-ілюстрацій `cat-01.svg` … `cat-08.svg` — тимчасові заглушки,
  їх можна видалити після заміни реальними фото.

## 4. Форма зворотного зв'язку

Форма на сторінці «Контакти» використовує **Netlify Forms**:

- атрибути `data-netlify="true"` і приховане поле `form-name` уже додані;
- заявки з'являться в панелі Netlify: **Forms → contact**;
- після надсилання користувач потрапляє на сторінку `/diakuiemo/`;
- додайте email-сповіщення в Netlify: **Forms → Settings → Form notifications**.

Локально (`npm run dev`) форма не надсилає заявки — це нормально, вона
працює лише на опублікованому сайті Netlify.

Якщо потрібен інший сервіс (Formspree, Basin), змініть `action` форми в
[`src/pages/kontakt.astro`](src/pages/kontakt.astro).

---

## 5. Публікація на Netlify

1. Завантажте проєкт у GitHub/GitLab.
2. У Netlify: **Add new site → Import an existing project**.
3. Виберіть репозиторій. Налаштування підтягнуться з `netlify.toml`:
   - build command: `npm run build`
   - publish directory: `dist`
4. Натисніть **Deploy**. Сайт буде доступний за адресою
   `https://<назва>.netlify.app`.
5. Додайте власний домен: **Domain settings → Add a domain**.

Кожен `git push` у головну гілку автоматично оновлює сайт.

```
├─ public/
│  ├─ logo.svg                  # логотип
│  └─ images/animals/           # фото котів
├─ scripts/

├─ src/
│  ├─ config.ts                 # ★ УСІ змінювані тексти й контакти
│  ├─ content.config.ts         # схема профілю кота
│  ├─ content/animals/          # 130 профілів (Markdown)
│  ├─ components/               # шапка, підвал, картка, іконки
│  ├─ layouts/Base.astro        # HTML-каркас, SEO-мета
│  ├─ lib/format.ts             # вік, дати, відмінювання
│  ├─ pages/                    # сторінки
│  └─ styles/global.css         # дизайн
├─ astro.config.mjs
├─ netlify.toml
└─ package.json
```

## Корисне

- Перевірка типів і помилок контенту: `npx astro check`
- Попередній перегляд продакшн-збірки: `npm run build && npm run preview`
- Генерація sitemap відбувається автоматично під час збірки.
- Сайт адаптивний, підтримує клавіатурну навігацію та `prefers-reduced-motion`.
